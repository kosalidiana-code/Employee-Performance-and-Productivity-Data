# Employee-Performance-and-Productivity-Data
This project presents a complete AI-powered HR Intelligence System developed using Python, Machine Learning, and Power BI. The system helps HR departments improve hiring decisions, predict employee attrition, analyze workforce performance, monitor employee wellbeing, and ensure ethical AI practices.

## Key HR Findings
1. Employees with high overtime and low satisfaction had the highest attrition risk.
2. Training hours positively impacted employee performance scores.
3. Some departments showed significantly higher burnout risk levels.
## Ethical Concern
The main ethical concern was potential bias in attrition prediction and hiring recommendations. We addressed this issue by performing fairness audits across gender and age groups and ensuring transparent model evaluation.
